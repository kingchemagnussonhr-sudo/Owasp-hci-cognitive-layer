# Detection & Mitigation Matrix for Cognitive Vulnerabilities

| Cognitive Vulnerability | Detection Signal | Activated Mitigation |
|-------------------------|------------------|----------------------|
| CV-02 Confirmation Bias | Affective Congruence | Bias Warning System + Critical Reweighting |
| CV-02 Confirmation Bias | Low Narrative Entropy | Forced Disagreement Sampling |
| CV-01 Automation Bias   | Low Token-to-Claim Ratio | Information Density Barometer + Latency-Compensated Generation |
| CV-03 Anchoring Bias       | First-output fixation    | Multi-framing Injection + Order Randomisation |
| CV-03 Anchoring Bias       | No query reformulation   | Pre-commitment Protocol (user documents reasoning first) |
| CV-04 Cognitive Overload   | Output length >> task    | Progressive Disclosure Enforcement |
| CV-04 Cognitive Overload   | No follow-up after long output | Critical Content Surfacing (warnings at start+end) |
Expand this matrix later as more CV entries are defined via community work.
